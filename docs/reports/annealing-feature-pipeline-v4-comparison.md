# 焼鈍Feature Pipeline v2とv4の比較

## 比較の目的

Feature Pipeline v2は、raw LSとLSに強く結び付く時間温度特徴を同じベクトルへ入れる。
Feature Pipeline v4は、実時間のヒートパターンを正本とし、raw LSを予測特徴から外す。

この比較は、v4が合成デモデータ上で高精度だと示すものではない。
同じ親条件分割で数値挙動を比較し、LSの重複と係数の安定性を確認するために行った。
再生成可能な数値は [比較レポートJSON](annealing-feature-pipeline-v4-comparison.json) に保存している。

## 評価条件

`material_workbench_process_v1.xlsx`から、焼鈍後特性の学習条件として有効な親条件を抽出した。
同じ成分と工程条件に属する反復測定は平均し、親条件をまたいで5分割した。

両pipelineの比較には同じ180親条件と同じfoldを使った。
モデル差を持ち込まないため、各fold内で入力を標準化し、固定RBF kernel ridgeで評価した。
このモデルはactive Packageの学習結果を再現するものではなく、表現の比較に固定した共通の物差しである。

| 目的変数 | 親条件 | v2 MAE | v4 MAE | v2 RMSE | v4 RMSE |
|---|---:|---:|---:|---:|---:|
| 引張強さ | 142 | 57.84 MPa | 58.52 MPa | 398.98 MPa | 399.00 MPa |
| 降伏強さ | 142 | 41.68 MPa | 42.29 MPa | 295.93 MPa | 295.97 MPa |
| 全伸び | 142 | 2.62% | 2.64% | 15.99% | 15.99% |
| 穴広げ率 | 130 | 4.50% | 5.51% | 14.72% | 23.28% |

v4は、引張強さ、降伏強さ、全伸びでv2とほぼ同じ誤差だった。
穴広げ率ではこの固定モデルによるv4の誤差が大きい。
したがって、この比較から「v4の方が精度がよい」とは判断できない。

## LSと時間温度特徴の重複

180親条件について、LSとv4の時間温度特徴のPearson相関を計算した。
絶対値が大きかった項目は次のとおりだった。

| 特徴量 | Pearson r |
|---|---:|
| 最高温度 | -0.699 |
| 最大加熱速度 | 0.694 |
| 最高温度−Ac1目安 | -0.681 |
| 最高温度−Ac3目安 | -0.646 |
| 800→500℃冷却の観測有無 | -0.590 |

これはLSがこれらの特徴の原因だと示す結果ではない。
設備条件、温度設定、デモデータの生成規則が一緒に変わるため、LSが時間温度特徴の代理変数として働き得ることを示している。

v2の標準化linear ridgeでLS係数をfoldごとに確認すると、符号一致率は引張強さ0.8、降伏強さ0.8、全伸び1.0、穴広げ率0.6だった。
引張強さと降伏強さは各1fold、穴広げ率は2foldで符号が変わった。
raw LSの寄与を単独の安定した効果として読むことはできない。

## 採用判断

v4を採用する理由は、合成データ上の精度差ではなく入力契約にある。
実時間のヒートパターンがあればLSなしでも同じ特徴量を計算でき、LS連動入力では設備位置を保った時間列へ変換してから同じpipelineへ渡せる。
これにより、LSとLS由来の時間情報を同じ予測ベクトルへ重ねない。

v2 Packageは既存Projectと保存済み予測の再現に必要なため、version 2の計算経路を残す。
新しいv4 Packageへ既存Projectを自動で切り替えず、新しいProjectまたは検討の続きで明示的に選ぶ。

穴広げ率の誤差差と、少数の極端な時間温度特徴はModel Packageを評価するときの確認事項として残す。
active Packageでは支持範囲と予測区間を併記し、この比較値を材料現象の因果や実運用精度の根拠には使わない。
