# UI fidelity ledger

基準: `docs/design/candidate-workbench.png` と 1600 × 1000 の実描画を同じ確認回で比較した。

| 観点 | 判定 | 実装上の扱い |
|---|---|---|
| 濃紺ヘッダー、白基調、青い主操作 | 一致 | 共通トークンと3カラム判断面を維持 |
| 入力・比較・予測根拠を同時に見る構造 | 一致 | 左インスペクタ、中央判断面、右エビデンス |
| 候補比較表の向き | 意図的変更 | ユーザーフィードバックに従い、1行=候補・列=全14成分/工程/予測へ完全転置 |
| 多変数の可読性 | 改善 | 候補名をstickyにし、列グループと横スクロールを追加 |
| ヒートパターン比較 | 一致 | 選択候補を青、比較候補を橙で重ね、点追加/削除/編集に対応 |
| 応答曲線と予測幅 | 簡素化 | モデルの条件付き1変数応答だけを表示し、根拠のない多軸曲線は描かない |
| エビデンス | 改善 | grouped OOF残差区間、支持度、類似親条件、モデル/データ来歴を実APIから表示 |
| 操作の実動 | 確認済み | 行選択、セル編集、予測更新、実測固定比較、LHS探索、系譜候補化、snapshot復元 |

最終実描画: `docs/qa/candidate-table-final.png`
