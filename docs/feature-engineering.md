# 特徴量パイプライン

## 契約

`feature_pipeline.build_feature_bundle` は候補組成、焼鈍条件、時間–温度点列から、固定順の `float64` ベクトルを作る。契約識別子は `metallurgy-thermal`、versionは `2.0.0` である。順序・単位・意味・groupは `FEATURE_DEFINITIONS` を唯一の定義とし、出力配列は誤変更を防ぐため読み取り専用で返す。熱延も同じ `FeatureBundle` を使い、`metallurgy-hot-rolling` version `2.0.0` として区別する。

組成はすべて `%` とする。対応元素は `C, Si, Mn, P, S, Al, Cu, Ni, Cr, Mo, Ti, B, O, N` の14種である。欠損値を暗黙に0にはしない。学習データ中央値など、来歴が分かる補完値を `composition_defaults` として明示した場合だけ補完する。今回の正本ExcelにはCu列がなかったため、置換後データではCuを0%として記録している。

焼鈍の工程条件はLS `[mpm]` で、焼鈍履歴は時間–温度の縦持ち点列として保持する。熱延の工程条件は均熱温度、仕上げ温度、入側板厚、出側板厚、保持温度、保持時間である。

## 組成由来特徴量

| 特徴量 | 式 | 単位 | 解釈と限界 |
|---|---|---|---|
| CEIIW | `C + Mn/6 + (Cr+Mo)/5 + Ni/15` | % | 焼入性・溶接性の古典的指標。適用規格や鋼種を越えた絶対判定には使わない。 |
| Pcm | `C + Si/30 + (Mn+Cr)/20 + Ni/60 + Mo/15 + 5B + Cu/20` | % | 低炭素鋼の溶接割れ感受性に関する組成指標。水素量・拘束・板厚を含まない。 |
| C×Mn | `C * Mn` | %^2 | CとMnの相互作用をモデルが低次数で扱えるようにする経験的項。機構式ではない。 |
| Si+Al | `Si + Al` | % | 脱酸・固溶元素量の粗い合計。酸化物形態や有効固溶量は表さない。 |
| Cr+Mo | `Cr + Mo` | % | 焼入性に寄与する元素の粗い合計。両元素を同一効果と仮定しない。 |
| microalloy合計 | `Ti + B` | % | 取得可能な微量添加元素だけの合計。Nb、Vがデータにないため、一般的なmicroalloy総量ではない。 |

これらは冶金的な事前構造を与える補助変数であり、因果量や規格適合判定ではない。元の14成分も同時に保持するため、合計特徴量による情報消失はない。

## ヒートパターン由来特徴量

入力点間の温度は区分線形とみなす。

| 特徴量 | 単位 | 定義 |
|---|---|---|
| peak | degC | 入力点列の最高温度。 |
| 最大加熱速度 | degC/s | 各区間の正の `ΔT/Δt` の最大値。 |
| 95% peak保持 | s | `T >= 0.95 * peak` である時間の総和。閾値交差時刻を線形補間する。 |
| 700℃以上時間 | s | `T >= 700℃` の総時間。閾値交差を線形補間する。 |
| 600℃超過積分 | degC*s | `∫ max(T(t)-600, 0) dt`。交差区間を分割した台形積分である。 |
| 800→500相当冷却速度 | degC/s | 最初のpeak以後、下降時の800℃交差から、その後の500℃交差までの `300/Δt`。両交差がなければ0で補完する。 |
| 800→500冷却速度の観測フラグ | 1 | 両交差を観測できた場合だけ1。速度0と組み合わせ、物理的ゼロと観測不能を区別する。 |
| 再加熱回数 | count | 冷却から加熱へ反転し、その上昇幅が25℃以上の excursion 数。25℃未満は測定・入力ノイズとして数えない。 |
| 再加熱有無 | 1 | 再加熱回数が1以上なら1。 |

点列が炉内の実温度を十分に表すこと、点間を線形補間できることが前提である。最大加熱速度はサンプリング間隔に敏感である。800→500冷却速度の0は観測フラグと必ず組み合わせて解釈する。モデル利用時はsupport判定と元点列を併記する。

Excelの `高温保持時間[s]` と `再加熱工程あり` は工程側で作成された既存の説明変数であり、このpipelineの点列由来定義とは同一ではない。前者を正解値として上書きせず、`time_at_or_above_95pct_peak_s` と25℃以上のexcursion回数を、自由入力した点列にも再現できる独立した特徴として固定する。比較監査では定義差をデータ不良と誤認しない。

## 焼鈍応答曲線の操作契約

焼鈍タスクの応答曲線では、ヒートパターンの単一点時刻を設計変数にしない。ラインスピードを `LS_new` へ変更するときは、入口時刻を原点として全時刻差を `LS_base / LS_new` 倍し、同時に工程条件のLSも更新する。これにより、設備上の位置関係を保ったまま全工程の滞在時間が一括で変化する。

工程温度は点番号ではなく `stage_name` で指定する。同名点が複数ある場合、現在値を同名点の平均温度とし、試行値との差 `ΔT` を全点へ加えて工程内の温度形状を保つ。候補に工程名がない場合は、プロジェクトに保存した入口からの工程位置 `[m]` と候補LSから `t = t_entry + 60 * position / LS` を求め、既存の区分線形 `T(t)` 上へ仮の点を挿入する。基準温度には挿入位置の補間温度を使うため、基準点では熱履歴特徴と予測が変わらない。工程位置が候補の履歴範囲外なら外挿しない。

この操作は既存の時間–温度列を変換して同じ特徴量pipelineへ渡すため、モデルPackageの再学習を必要としない。ただし現モデルが学習するのは上表の集約特徴であり、工程名そのものの固有効果ではない。異なる工程操作が同じ集約特徴になる場合は区別できず、工程別効果が必要になった時点で特徴量契約とPackageを改版する。

## 切削摩耗（flank-wear-v1）特徴量

`cutting-flank-wear` pipeline（`flank_wear_feature_pipeline.py`）は、試作材成分12元素（C/Si/Mn/Cr/Ni/Mo/V/W/Co/Ti/Al/Cu）、被削材特性（硬さHV・引張強さMPa）、工具（耐摩耗指数・耐欠損指数・ノーズR・すくい角・成膜方式one-hot）、切削条件（Vc・logVc・送り・切込み・クーラント方式one-hot・断続フラグ・ホルダ剛性順序値）、および切削距離由来特徴（`log(1+距離)`と、速度・硬さ・耐摩耗指数との相互作用）を固定順で出力する。

切削距離は利用者が設計する変数ではなく摩耗曲線の横軸である。候補入力では「評価点」として1点の距離を持ち、曲線そのものは応答曲線API（変数=`cutting_distance_m`）が提示する。学習単位は摩耗測定行（試験×距離）で、品質評価は試験（run）単位のleave-one-outとする。目的変数は`log(1+VB)`空間で学習し、µmへは単調変換で戻す（分位点は厳密に対応する）。

## テスト方針

`test_feature_pipeline.py` は次を固定する。

- 一つの代表的な加熱–保持–冷却経路について全主要値をgolden化する。
- 時間軸を定数倍すると滞在時間・積分は同じ倍率、速度は逆倍率になる。
- 閾値時間と超過積分は非負で、温度上昇に対して増える。
- 25℃以上の再加熱だけを数える。
- 欠損、未知元素、非有限組成を黙って特徴量化しない。

goldenを更新するときは数値をテストに合わせて変更せず、式・単位・冶金的意味の変更としてレビューし、特徴量パイプラインのversionも更新する。
